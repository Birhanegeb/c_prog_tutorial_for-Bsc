# C Programming Tutorial and Assignments

This repository contains C programming practice exercises and coursework for BSc Computer science students. It includes assignment folders with problem solutions written in C.

## Overview

The projects in this workspace are organized by assignment and each file focuses on a specific programming concept such as:

- basic arithmetic and input/output
- control structures
- functions and parameter passing
- arrays and strings
- loops and conditionals
- pattern printing and problem solving

## How to Run a Program

Open any `.c` file in a C compiler environment and compile it using GCC:

```bash
gcc -Wall -o program_name program_name.c
./program_name
```

Example:

```bash
gcc -Wall -o a1_p1 a1_p1.c
./a1_p1
```
